# ダッシュボードへの作り替え — 用語表

会社ごっこの見立てをやめ、CLI セッションの管理画面にする。
**機能は落とさない。** 演出だけを外し、数字と操作を前に出す。

## 中核の名前

| 旧 | 新 | 備考 |
|---|---|---|
| `Employee` | `Session` | CLI セッション 1 本 |
| `Office` | `Dashboard` | 画面全体の状態 |
| `persona` | `name` / `color` / `role` | 人格をやめ、識別のための最小限に |
| `specialty` | `role` | システムプロンプトに効く実機能なので残す |
| `tone` | （削除） | 口調は演出だけのもの |
| `sprite` / `palette` | `color` | 一覧で見分けるための色 |
| `seatIndex` | `slot` | 表示順 |
| `hire()` | `createSession()` | |
| `retire()` | `archiveSession()` | |
| `rehire()` | `unarchiveSession()` | |
| `subordinates` | `subagents` | |
| `nextMemo` | `nextPrompt` | |

## 消すもの

| 消すもの | 理由 |
|---|---|
| 経験値・レベル・役職 | 実態のないゲーム要素 |
| 給料・予算・人件費 | 月額固定で、そもそも擬似通貨だった |
| レベルアップ演出 | |
| 演出台詞（口調） | |
| 人物のドット絵・まばたき | |
| 「定時まで」「残業中」 | 使用量の実測表示に統合済み |

## 残すもの（数字と機能）

- コンテキスト使用率（claude は正確値 / codex は概算）
- 稼働時間・稼働率・状態
- 実行したタスク数・編集ファイル数・コマンド数・トークン
- 使用量（claude `/usage` / codex のセッション記録）
- 承認フロー（権限拒否 → 差分表示 → 承認して再実行）
- 次に送るプロンプトの下書き
- worktree 隔離・実行ロック
- ネットワーク復帰
- サブエージェントの表示
- 永続化・再起動後の復帰
- 既存セッションの取り込み
