# AGENT DASHBOARD

`claude` と `codex` のセッションをまとめて見るターミナルのダッシュボードです。
どのセッションが何をしていて、コンテキストをどれだけ使い、いくらトークンを
消費したかが 1 画面で分かります。そのまま会話に入って指示を出せます。

## 動かす

```bash
npm start                    # ~/.agent-dashboard を使って起動
npm start -- --cwd ~/myrepo  # 既定の作業ディレクトリを指定
npm start -- --ascii         # ブロック文字を使わない描画
npm start -- --no-anim       # 動きを止める
npm start -- --no-bell       # 端末ベルを鳴らさない
```

必要なもの:

- Node.js 22.6 以上（TypeScript をそのまま実行します。ビルド不要）
- `claude` または `codex` のどちらか。両方あれば両方使えます

端末は **100x30 以上**にしてください。

## 基本の流れ

1. `n` でセッションを追加する（CLI・役割・作業ディレクトリを選ぶ）
2. `Enter` で会話に入り、プロンプトを書いて `Enter`
3. 一覧で状態・コンテキスト・トークンを見る
4. 終わったら `e` で次に送るプロンプトを書いておくと、`Enter` でそのまま送れる

主なキー（全一覧は `?`）:

| キー | できること |
|---|---|
| `↑↓` / `kj` | 行を選ぶ |
| `Enter` | 開く（承認待ちなら内容、下書きがあれば送信） |
| `e` / `d` | 次に送るプロンプトの編集 / 削除 |
| `n` / `X` | 追加 / アーカイブ |
| `Ctrl+C` | 実行中のタスクを中断 |
| `R` | 再接続 |
| `L` `a` `s` `,` `?` | ログ / 履歴 / 統計 / 設定 / ヘルプ |
| `q` | 終了 |

一覧の右側に出る印: `W` worktree で隔離 / `P` 下書きあり / `!` 承認待ち / `S` サブエージェント稼働中

## できること

### 使用量

両方の残量が上部に出ます。

- **claude** — `claude -p "/usage"` を叩きます。CLI 内部で処理されるので
  **モデル呼び出しは起きず、課金もされません**（約 0.4 秒）
- **codex** — `~/.codex/sessions/` の記録にある `rate_limits` を読みます

起動時・5 分ごと・実行が終わったときに取り直します。取れなかったときは
数字を作らず、その旨を出します。

### 会話は途切れません

1 ターンごとに CLI プロセスを起こして終える方式ですが、会話そのものは CLI 側の
セッションストアに残ります。**落として立ち上げ直しても、続きから話せます。**

### マークダウンを読める形で出す

モデルの応答に含まれる見出し・箇条書き・表・コードブロックは、記号のまま
出さずに装飾へ置き換えます。

```
  │ やったこと                      ← ## 見出し
  │
  │ src/auth/session.ts を直しました。期限切れの判定が UTC を仮定していたためです。
  │                                   ↑ `コード` は色付き、**太字** は強調
  │ • 検証を Date.now() 基準に変更   ← - 箇条書き
  │   • 期限切れ                     ← 入れ子は下げる
  │
  │   export function isExpired(token: Token): boolean {   ← コードブロックは
  │     return token.expiresAt <= Date.now();                 背景を変えて素通し
  │   }
  │
  │  項目     │ 変更前       │ 変更後   ← 表は桁を揃える
  │  ─────────┼──────────────┼───────
  │  判定基準 │ ローカル時刻 │ UTC
```

**中身は変えません。** 記号を装飾に置き換えるだけです。

- コードブロックの中は一切解釈しません（`**bold**` があってもそのまま）
- リンクの URL は捨てずに残します
- 記法として成立していない記号（`2 * 3`、`snake_case`）はそのまま出します

### 複数行を書く

会話の入力欄で改行するには **`Ctrl+J`** を押します。`Enter` は送信です。

`Alt+Enter` と `Shift+Enter` でも改行できますが、**この 2 つは端末やウィンドウ
マネージャに横取りされることがあります**（Alacritty などは Alt+Enter を全画面
切り替えに使います）。`Ctrl+J` はどの端末でもそのまま届くので、こちらを既定の
案内にしています。

### 会話を遡る

会話画面の `Ctrl+U` / `Ctrl+D` で 2 行ずつ。`Shift` を足すと 5 行ずつ。

`Ctrl+Shift+U` は、端末が修飾を報告しない限り `Ctrl+U` と同じバイトで届く。
起動時に xterm の modifyOtherKeys（水準 1）を立てて報告させているが、
対応していない端末のために `Alt+u` / `Alt+d` も 5 行ずつにしてある。
前回までのやり取りも起動時に読み戻すので、落として立ち上げ直しても遡れる。
上下に続きがあるときは `↑ さらに N 行` と出る。

一覧の左端の印は、動いている間は回る印、止まっていて**まだ見ていない結果**が
あれば `✓`（成功）か `×`（失敗）。その会話を開くと消える。

## 次に送るプロンプト

作業が終わったあとに送りたいことを、何件でも控えておける。順番は持たない。

| | |
|---|---|
| `e` | 控えを 1 件書き足す（会話中は `Alt+e`） |
| `p` | 控えの一覧を開く（会話中は `Alt+p`）。`↑↓` で選び `Enter` で送る |

**控えは自動では送られない。** 送るのは一覧で選んで `Enter` を押したときだけで、
作業が終わっても、`Enter` を押しても、勝手には出て行かない。
返答を見てから別のことを頼みたくなる場面のほうが多く、
一度送ってしまうと取り消せないため。

## スラッシュコマンド

会話で `/` を打つと候補が出ます。`Tab` か `↑↓` で選んで `Enter` で確定、
もう一度 `Enter` で送ります。

```
  /code-review                                        1/7
  /compact
  /config
  /context
┌────────────────────────────────────────────────────────┐
│ > /co▏                                                 │
└────────────────────────────────────────────────────────┘
 [Tab/↑↓]候補を選ぶ  [Enter]決定  [Esc]やめる
```

候補は**CLI が返した実際の一覧**です（起動時に使用量と一緒に取得しています。
モデル呼び出しは起きません）。存在しないコマンドは出ません。`/doctor` のように
端末でしか動かないものも除いてあります。

`/usage` `/context` `/compact` などは CLI 側で処理されるので、**トークンを
消費しません**。

**codex には出ません。** codex は `exec` モードでスラッシュコマンドを解釈せず、
ただのプロンプトとして送られてトークンを消費するためです。うっかり送ろうとすると
確認の表示が出ます。

### 承認

権限が足りずにツールが拒否されると、承認待ちになります。何をしようとしたかが
**差分まで見える**ので、`y` で許可するとその操作だけを通して再実行します。
`a` を押せば以後そのツールは常に許可します。

### 既存の会話を取り込む

端末で直接始めた会話も一覧に取り込めます。`n` →「追加方法」を
**既存の会話を取り込む** に切り替えると、保存されている会話が新しい順に並びます。
選ぶ前に中身が見え、取り込むと**これまでのやり取りがそのまま会話に入ります**。

### ネットワークが切り替わっても続きます

WiFi を切り替えると、実行中のセッションだけを止めて自動で復帰させます。
このとき**元のプロンプトは再送しません**。「未完了なら続きから」と状態確認を
挟むので、同じ編集が二重に入りません。

### サブエージェント

claude がサブエージェントを使うと、詳細に種別・使用ツール・消費トークン・
作業時間が出ます。

### 数字はすべて実測です

- **コンテキスト** — claude は正確値、codex は概算（`~` が付きます）
- **稼働率** — 実際に動いていた時間の割合
- **トークン** — 実際の消費量
- **使用量** — CLI が返す残量そのもの

## スラッシュコマンド

claude は本体のコマンドをそのまま使える（候補も本体が返した一覧から出す）。

codex は非対話モード（`codex exec`）でスラッシュコマンドを解釈しないため、
よく使うぶんだけダッシュボード側で答える。CLI を呼ばないので実行の枠を使わない。

| | |
|---|---|
| `/status` | 状態・コンテキスト・使用量・作業場所 |
| `/model` | いまのモデルと選べる一覧。引数を付けると変更（次のターンから） |
| `/sandbox` | サンドボックスの設定を見る |
| `/compact` | コンテキストを圧縮する |
| `/help` | 使えるコマンド一覧 |

`/model` の一覧と既定値は codex 自身が置いているファイルから読む。推測はしない。

- `~/.codex/config.toml` — 既定のモデルと推論の深さ
- `~/.codex/models_cache.json` — codex が取得したモデル一覧（`visibility: list` のみ）

これ以外を codex に打った場合は送らずに知らせる。黙って送ると、ただの指示文として
モデルに渡ってしまうため（`docs/phase0/FINDINGS.md` §9）。

## データの置き場所

```
~/.agent-dashboard/
  config.json            設定
  dashboard.json         画面の状態
  history.json           月次の集計
  sessions-meta/*.json   セッション（識別名・集計・下書き・CLI セッション ID）
  logs/<id>/
    raw.jsonl            CLI の生出力（無加工）
    tasks.jsonl          タスク履歴
  worktrees/<id>/        git worktree
  locks/                 実行ロック
```

置き場所は `AGENT_DASHBOARD_HOME` で変えられる（旧名の `VO_HOME` も受け付ける）。

かつては `~/.virtual-office` だった。旧名のディレクトリが残っていれば起動時に一度だけ
`~/.agent-dashboard` へ移す。ただし移すのは新しい方がまだ無いときだけで、両方あるときは
何もせず起動時に知らせる（旧版のダッシュボードが動いたまま終了して旧名へ書き戻した場合に、
新しい状態を古いもので潰さないため）。

```

同じディレクトリに 2 つ目を追加すると、git リポジトリなら自動で worktree を
切って隔離します。アーカイブ時、未コミットの変更があれば worktree は消しません。

設定は `config.json` を編集して再起動してください。現在の値は `,` で確認できます。

## 開発

```bash
npm test          # オフラインのテスト（速い）
npm run typecheck # 型チェック
npm run check     # 上の両方
npm run test:live # 実 CLI を叩くテスト（課金と時間がかかります）
npm run demo -- --plain   # 画面をテキストで確認
```

- 実行時の依存パッケージはありません
- テストは Node 内蔵のランナーを使います
- 画面のテストは色を落としたプレーンテキストで検証するので、レイアウト崩れが
  機械的に検出できます

ドキュメント:

- `docs/SPEC.md` — 仕様書
- `docs/RENAME.md` — 用語表（会社の見立てからダッシュボードへ移した記録）
- `docs/phase0/FINDINGS.md` — CLI の実挙動を採取した結果
- `docs/NETWORK-CHECK.md` — ネットワーク復帰の確認手順
